# Rive 编辑器翻译

三端共用 `translation.js`，词典为 `translation.json`，完整字体位于 `fonts/`。
应用仅负责下载、缓存、开关和网页桥接。脚本在本地注入执行，不由网页直接下载字体。

## 发布

修改脚本、词典或字体后，运行 `python3 tools/update-translation.py`。
该命令只更新翻译日期版本、文件哈希及契约文件哈希，不修改宿主契约版本或 AI 规则版本。
把资源和元数据一起发布。管理页修改词典时仍使用原有“保存并发布”流程。

`rive-editor/release.json` 是三端直接读取的独立下载入口，不等待宿主规则下载。
发布工具从 `contracts/schema-v3/contract.json` 的 `translation.riveEditor` 生成该文件，
同时保留旧应用使用的元数据。
`scriptUrl` / `scriptSha256` 指向共享脚本；其余字段描述词典、字体和翻译参数。
修改翻译参数也应更新翻译日期版本。脚本注入时只替换两个占位符：
`__RIVE_EDITOR_CONFIG__`（当前完整版本配置）与 `__RIVE_EDITOR_DICTIONARY__`（词典对象）。
脚本不得依赖某一平台存在：Apple 字体走 `quRiveFont` 桥接，其他平台使用同一字体地址的本地拦截。

## 缓存

每次冷启动首次需要时，有完整缓存就立即使用，并后台检查一次更新；无缓存则等待首次下载。
已启用的会话固定使用同一版本，后台下载的新版本在下次冷启动使用。按内容哈希存放资源，
全部文件下载完整才原子替换 `active.json`；更新失败继续使用原来的完整版本。
首次获取失败会显示详情，再次手动打开开关可重试。翻译更新通知包含日期版本。

云端脚本更改受应用现有网页桥接能力约束；新增原生桥接仍需要更新应用。
