# 千机百变（Qianji Baibian）

> 千机百变（应用包名 com.bolin.one）是一款以 Rive 驱动的屏幕美化与互动创作工具，支持 HarmonyOS、Android 与 Apple 平台。它让动画能够响应触摸、传感器和数据变化，并提供 Rive 调试、脚本运行、资源包制作与可选同步能力。

## 产品定位

- Rive 互动内容：用动画与状态机表达触摸、传感器和数据变化，让屏幕内容可以实时回应。
- 个人与家庭陪伴：支持拟人角色、互动桌宠与 AI 陪伴设计，声音、触摸与传感器都可以成为角色回应的方式。
- 异形屏幕：圆屏、长条屏等屏幕可用作家庭信息面板与互动中枢，展示时间、天气与设备状态。
- 学习与创作：提供 Rive 中文课程、调试台、在线编辑器、JavaScript 应用脚本与资源包制作台。
- 隐私与本地优先：基础功能无需应用账号，不含第三方广告或行为追踪；数据默认保存在本机，是否同步由用户决定。

## 平台与同步

- HarmonyOS：使用系统账号与端云服务同步资源包和应用脚本。
- Android：可使用用户自行配置的 WebDAV 服务同步资源包和应用脚本。
- Apple：使用系统账号与 iCloud 同步资源包和应用脚本。
- 三端使用同一套资源包、应用脚本、动态 UI 与 QVMI 规则；平台独有能力只在相应系统中生效。

## 主要能力

- Rive 调试台与在线编辑器。
- 数据流检查器与运行时分析仪。
- JavaScript 应用脚本。
- schema-v3 资源包制作、导入与运行。
- Rive、JavaScript、动态 UI 与宿主能力之间的数据交互。
- 可选的文件同步。
