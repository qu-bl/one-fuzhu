千机百变 — Foreground service demonstration

Android package: com.bolin.one. These recordings show the application running on a Pixel Tablet Android emulator. The displayed Rive layout is sample content; its weather and accessory indicators are artwork, not live device or weather readings.

1. User starts the overlay, then leaves the application

The user selects a local resource package and explicitly opens its floating window. The visible Rive content remains on screen when the application is sent to the background. This is the user-visible task supported by FOREGROUND_SERVICE_SPECIAL_USE.

2. User stops the overlay

The user returns to the application's floating-window settings and closes the overlay. The visible floating window disappears. The overlay is optional and is not started for advertising, downloading, or covert data collection.

Review navigation: 应用内 (In-app) → upper-right resource button → 悬浮窗 (Floating window) → select a resource package → 设置 (Settings) → 打开悬浮窗 / 关闭悬浮窗 (Open / Close floating window). The Android “Display over other apps” permission is required.
